# Platform Architecture: SWADE Campaign Manager

## Концепция

Это не конструктор персонажей с дополнительными фичами — это **платформа управления TTRPG-кампанией**, построенная на системе SWADE. Мир (World) — корневой контекст для всей работы: персонажей, локаций, НПС, квестов, снаряжения, рас.

Граф сущностей — это внутренняя структура данных платформы. Пользователь работает через **формы**, которые показывают свой «уровень» графа. Глобальная визуализация графа — вспомогательный инструмент для анализа и будущей интеграции с ИИ.

## Структура верхнего уровня

```
[World Picker]  [+]          ← выбор мира + создать мир
┌──────────────────────────┐
│  SIDEBAR                 │
│  - Трекер боя            │
│  - Персонажи             │
│  - Справочники           │
│  - Конструктор рас       │
│  - География мира        │
│  - Города / Локации      │
│  - Магазины              │
│  - НПС                   │
│  - Квесты                │
│  - Бестиарий             │
└──────────────────────────┘
```

### World Picker
- Dropdown со списком всех миров
- Маленькая квадратная кнопка (иконка планеты) — создать мир
- Если миров нет: одна широкая кнопка «Создать мир» на всю ширину picker + кнопки
- Выбранный мир — активный контекст: все разделы сайдбара показывают данные этого мира
- Без мира: доступны только Трекер боя и Персонажи (без привязки)

## Мир (World)

При создании мира автоматически создаётся корневая сущность **«Мир»** в графе. Это единственная некастомная сущность — её нельзя удалить без удаления всего мира.

```typescript
interface World {
  schemaVersion: number
  id: string
  name: string
  summary: string
  settingRules: SettingRules        // правила игрового мира
  entities: WorldEntity[]
  relationships: WorldRelationship[]
}

interface SettingRules {
  skillPointsBudget: number         // default: 12
  attributePointsBudget: number     // default: 5
  // будущие правила: powerPoints, extraAttributes, etc.
}
```

## Справочники (Handbooks)

Двухуровневая система:

| Уровень | Источник | Кто может менять |
|---|---|---|
| Системный (SWADE) | Зашит в приложение | Нельзя изменить |
| Мировой | Хранится в World | Ведущий в контексте мира |

Мировой уровень может:
- **Добавлять** новые элементы (кастомное снаряжение, кастомные черты)
- **Переопределять** системные элементы (другая цена, изменённое описание, баланс)

### Разделы справочников
- Расовые особенности (Racial Abilities)
- Черты (Edges)
- Изъяны (Hindrances)
- Вооружение (Weapons)
- Снаряжение (Gear)
- Ездовые животные и машины (Mounts & Vehicles)
- Мистические силы (Powers)

---

## Персонажи (Characters)

- Могут существовать **без привязки к миру** (standalone)
- При создании внутри контекста мира — автоматически получают `worldId`
- Список персонажей в сайдбаре показывает только персонажей текущего мира (+ фильтр «без мира»)
- `settingRules` при редактировании берутся из мира персонажа; без мира — SWADE defaults
- Персонаж-НПС может быть одновременно сущностью в графе мира

## Модуль: География мира

Иерархическая навигация по пространственным сущностям мира. Возможные реализации (определяется позже):
- Карточная сетка с фильтрами
- Загружаемая карта с метками (город = метка → форма города)

### Иерархия
```
Мир
└── Регион / Территория
    └── Город / Поселение / Локация
        ├── Магазин (→ товары из справочника + наценки / кастомные цены)
        └── НПС (→ квесты, диалоги, связи)
```

### Навигация через форму
Форма города показывает: магазины, НПС, связанные квесты — нажатие на любую из них открывает соответствующую форму.

---

## Сайдбар: прямые разделы

Помимо навигации через Географию, следующие типы сущностей доступны напрямую из сайдбара как плоские списки с поиском и фильтрами:

| Раздел | Тип сущности | Связи |
|---|---|---|
| Города / Локации | Location | Регион, НПС, Магазины, Квесты |
| Магазины | Shop | Город, Товары (из справочника) |
| НПС | NPC | Город, Квесты, Фракции |
| Квесты | Quest | НПС (выдающий), Локации, награды |

## Граф мира (World Graph)

Текущий World Builder сохраняется как отдельный раздел / режим просмотра. Функция:
- Визуализация всех связей между сущностями
- Инструмент для ведущего чтобы видеть «большую картину»
- Будущий источник данных для ИИ-анализа (связи, паттерны, зависимости)

Связи между сущностями строятся **внутри форм**, граф их только отображает.

---

## Трекер боя (Combat Tracker)

Существующий модуль. Работает независимо от контекста мира. В будущем — подтягивает комбатантов из персонажей и бестиария текущего мира.

---

## Конструктор рас (Race Builder)

Позволяет создавать расовые шаблоны с набором:
- Расовых особенностей (из справочника + кастом)
- Стартовых навыков / характеристик
- Размера (SWADE Size system)

Созданные расы попадают в «Мировой» уровень справочника расовых особенностей.

---

## Бестиарий (Bestiary)

Коллекция существ и противников с полными статблоками SWADE.
- Системный уровень: стандартные существа
- Мировой уровень: кастомные / адаптированные существа
- Используется Трекером боя для импорта комбатантов

---

## Граф сущностей — типы и связи

```
WorldRoot
  ├─[contains]─ Region
  │               └─[contains]─ Location
  │                               ├─[located_in]─ Shop
  │                               │                 └─[sells]─ HandbookItem
  │                               └─[lives_in]─ NPC
  │                                               └─[gives]─ Quest
  ├─[member_of]─ Faction
  │               └─[knows]─ NPC
  └─[character]─ Character (PC/NPC)
```

## Текущее состояние vs. Целевое состояние

| Компонент | Сейчас | Цель |
|---|---|---|
| Character Library | Глобальная | Per-world + standalone |
| World Builder | Граф-редактор = основной UI | Один из разделов мира |
| Setting Rules | Нет | `settingRules` в `World` |
| Справочники | Нет | Системные + мировые |
| НПС | Нет | Форма + граф-сущность |
| Квесты | Нет | Форма + граф-сущность |
| География | Нет | Иерархическая навигация |
| Конструктор рас | Нет | Per-world |
| Бестиарий | Нет | Системный + per-world |
